Generate a standup summary of work completed in this session.

## Gather Context
1. Run `git diff main...HEAD --stat` to see all changes on this branch
2. Run `git log main..HEAD --oneline` to see commits made
3. Review the conversation for tasks completed

## Summary Format

### Completed
- List concrete accomplishments (files changed, features added, bugs fixed)
- Reference specific files and functions where relevant

### In Progress
- Work started but not yet finished
- Blockers or questions that need answers

### Next Steps
- What should be done next to continue this work
- Any follow-up tasks identified during the session

Keep it concise and factual. Focus on what was actually done, not what was discussed.

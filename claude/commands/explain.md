## Analysis Structure

### Overview
- What is the purpose of this code?
- Where does it fit in the overall architecture?

### Key Components
- Main functions/types and their responsibilities
- Important data structures
- External dependencies

### Control Flow
- How does data flow through this code?
- What are the entry points and exit points?
- What are the key decision points?

### Edge Cases & Error Handling
- How are errors handled?
- What edge cases are covered?
- What assumptions does the code make?

### Gotchas & Complexity
- What parts are tricky or non-obvious?
- Are there any known issues or technical debt?
- What should someone modifying this code watch out for?

Keep explanations clear and focused. Use code references with file:line format.

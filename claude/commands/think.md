Think through this problem carefully before writing any code: $ARGUMENTS

## Step 1: Clarify the Problem
- What exactly is being asked?
- What is the expected outcome?
- What are the inputs and outputs?

## Step 2: Understand the Context
- What existing code is involved?
- What patterns does the codebase already use for similar problems?
- What are the constraints (performance, compatibility, etc.)?

## Step 3: Consider Approaches
- What are 2-3 different ways to solve this?
- What are the tradeoffs of each approach?
- Which approach best fits the existing codebase?

## Step 4: Identify Risks
- What could go wrong?
- What edge cases need handling?
- What assumptions am I making?

## Step 5: Outline the Solution
- What's the minimal change that solves the problem?
- What files need to be touched?
- What tests need to be written or updated?

Do NOT write code yet. Present your thinking and ask for confirmation before proceeding.
